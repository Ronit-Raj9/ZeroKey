01

What Is AdShell?

AdShell is an open-source AI coding assistant CLI that introduces a third tier between "free (no AI)" and "paid subscription" — attention-subsidized access. Instead of paying with a credit card, users watch a single ASCII advertisement before each AI call. That ad view triggers an x402 micropayment on Monad that pays for the AI API call. The entire loop completes in under 4 seconds.

📺

ASCII Ads in CLI

Terminal-native ad display. 3-second countdown. ASCII art + tagline rendered in a side panel using Ink.js.

⚡

x402 Micropayments

HTTP-native payments. No MetaMask popup. No gas estimation. The x402 client auto-signs and sends USDC in a request header.

🔷

Monad Settlement

10,000 TPS, 0.4-second blocks. Every impression and every AI payment settles on Monad before the user sees the response.

🤖

AI Proxy Gating

One gated endpoint. Valid x402 payment → Anthropic/OpenAI call. Streamed response back to CLI. Users never need API keys.

02

Problem & Solution

❌ The Three Broken Things

  • Premium AI APIs are paywalled. Claude, GPT-4, Gemini — all require a credit card + minimum spend. Billions of developers globally cannot access the best tools without financial infrastructure they don't have.
  • Micropayments haven't worked on the web. HTTP 402 was reserved in 1995 but left unimplemented for 30 years. Gas fees, latency, and account friction made sub-cent payments impossible — until x402 + Monad.
  • CLI tools have zero monetization layer. OpenCode (131k stars), Claude Code, Cursor terminal — none can subsidize free users at the infrastructure level. They either charge everyone or absorb cost themselves. No middle path exists.

✅ The AdShell Solution

  • Attention as currency. One 3-second ASCII ad = one AI call. The attention economy, applied to developer tooling for the first time.
  • x402 as the payment rail. Machine-to-machine HTTP payments. No accounts, no sessions, no human intervention. Lives inside HTTP headers.
  • Monad as settlement layer. 10,000 TPS means thousands of impression + API payment pairs per minute. Gas cost per transfer (~$0.0001) is 10× cheaper than the $0.001 payment amount.
  • Embedded wallet — zero UX friction. Wallet auto-generated on first run, private key stored locally. No setup, no faucet, no bridge. Users never know they have a crypto wallet.

Three Stakeholders

👨‍💻 The Free Developer

  • Student, open-source contributor, junior developer anywhere in the world
  • Installs AdShell for free via npm — one command
  • Sees ASCII ad banner before each AI prompt
  • Embedded wallet auto-created, zero setup
  • Never signs a transaction manually, never knows they have a wallet
  • Gets Claude / GPT-4 answers at zero direct cost

🏢 The Advertiser

  • Blockchain project, SaaS company, dev tool wanting developer reach
  • Uploads ASCII art creative to dashboard (or uses AI generator)
  • Sets budget in USDC — deposits into AdPool.sol on Monad
  • Defines targeting: language stack, OS type
  • Pays per verified impression — not per click, not per day
  • Real-time analytics: CPM, impressions served, remaining budget

⚙️ The AI Proxy (Protocol)

  • AdShell backend — the economic bridge between all parties
  • Holds actual Anthropic / OpenAI API keys — users never need them
  • Receives x402 micropayments to release AI access
  • Forwards payment header to Monad x402 Facilitator for on-chain verification
  • Streams AI response back to CLI after payment confirmed
  • Revenue covers AI API bills — self-sustaining model

System Architecture (5 Components)

AdShell System Architecture ──────────────────────────────────────────────────────── [CLI Application] [Ad Server] [Monad Testnet] ┌─────────────────┐ ┌───────────────┐ ┌──────────────────┐ │ Zone A: Chat │ │ GET /ad │ │ AdPool.sol │ │ Zone B: Ad Panel│ ──────► │ POST /claim │ ──────► │ claimImpression()│ │ Zone C: Footer │ │ GET /stats │ │ deposit() │ └────────┬────────┘ └───────────────┘ └──────────────────┘ │ ▲ │ x402 payment │ ▼ Ad Server calls [AI Proxy Server] contract on claim ┌─────────────────┐ [x402 Facilitator] │ POST /ai │ ┌───────────────────────────────┐ │ @x402/express │ ──────► │ molandak.org │ │ Anthropic SDK │ │ verifies EIP-712 signature │ └────────┬────────┘ │ executes USDC transfer │ │ │ returns tx hash │ ▼ └───────────────────────────────┘ [Anthropic API] Streams response

📟 System 1 — CLI Application

  • Framework: Ink.js (React-in-terminal) + Chalk for ANSI colors + DotEnv for config
  • Zone A — Main Chat Panel (70% width): Standard REPL — prompts in, AI responses stream out
  • Zone B — Ad Panel (30% width, right side): ASCII art, advertiser tagline, countdown timer. Auto-closes after impression settles
  • Zone C — Status Footer (full width): Wallet address (truncated), USDC balance, impression tx hash, payment tx hash, Monad explorer links
  • Embedded Wallet: EVM keypair generated on first run. Stored at ~/.adshell/wallet.enc encrypted with machine ID. All x402 signing happens silently in background
  • x402 Client: Wraps fetch with @x402/client — auto-constructs EIP-712 authorization, attaches as PAYMENT-SIGNATURE header, retries on 402

📢 System 2 — Ad Server

  • Framework: Express.js + Ethers.js for contract calls + in-memory session store (MVP)
  • GET /ad?wallet=0x... — returns ASCII creative + one-time session token
  • POST /claim — validates impression (≥3s elapsed, session token match, wallet match) then calls AdPool.claimImpression() on Monad
  • Anti-fraud: One-time session tokens, 3s minimum display time, wallet rate limiting, double-claim prevention
  • Ad Creatives: Stored as JSON — ASCII art string (20 lines × 40 chars), tagline (60 chars max), ANSI color codes, destination URL
  • MVP: 3 hardcoded ASCII ads served in round-robin — Kuru DEX, Monad Foundation, AdShell self-promo

⛓️ System 3 — Smart Contracts (Monad)

  • AdPool.sol — primary contract holding advertiser USDC deposits on Monad testnet
  • deposit(amount) — advertisers call to fund their campaign in USDC (6 decimal)
  • claimImpression(userWallet) — only callable by authorized Ad Server hot wallet. Transfers IMPRESSION_COST (1000 = $0.001) from active advertiser budget → user wallet
  • withdraw(amount) — advertisers pull unspent budget back anytime
  • USDC address (Monad testnet): 0x534b2f3A21130d7a60830c2Df862319e593943A3
  • Deployed via Foundry — forge script script/Deploy.s.sol --rpc-url https://testnet-rpc.monad.xyz

🤖 System 4 — AI Proxy Server

  • Framework: Express.js + @x402/express middleware + Anthropic SDK
  • Payment gate: POST /ai costs exactly $0.001 USDC on Monad testnet (eip155:10143)
  • Request lifecycle: Receive request → extract PAYMENT-SIGNATURE header → forward to Monad Facilitator (x402-facilitator.molandak.org) → verify EIP-712 + settle → get tx hash → forward to Anthropic → stream response
  • Model routing (MVP): Always routes to claude-haiku-4-5 (fastest, cheapest)
  • Gas sponsorship: x402 Facilitator covers Monad gas — user wallet needs zero MON. Gasless from user perspective
  • Streaming: SSE (Server-Sent Events) back to CLI for real-time token streaming

Why Monad Is Non-Negotiable

Each AI interaction generates two on-chain transactions — impression claim + API payment. At modest usage (1,000 users × 10 requests/day) that is 20,000 transactions per day. The math eliminates every other chain:

Chain TPS Settlement Gas per Transfer Viable?
Ethereum L1 ~15 TPS ~12 seconds ~$0.50 ❌ Gas > payout
Arbitrum / Optimism ~2,000 TPS ~2 seconds ~$0.01 ❌ Gas > payout
Base ~2,000 TPS ~2 seconds ~$0.001 ⚠️ Marginal
Monad 10,000 TPS ~0.4 seconds ~$0.0001 ✅ Perfect fit
💰

Gas 10× cheaper than payout

$0.0001 gas vs $0.001 payout = 10× margin. On Arbitrum, gas equals the payout. Economics break.

⚡

Settles during the ad display

0.4s settlement means the impression claim settles WHILE the user is still watching the 3-second ad. Completely invisible.

🏗️

x402 Facilitator already live

Monad has a deployed x402 facilitator at molandak.org. Working infrastructure out of the box — zero custom relay needed.

📈

10,000 TPS for scale

50 concurrent demo users = 100 simultaneous transactions. Monad handles this trivially. Any L2 would clog.

What to Skip (Save Time)

These are intentionally out of scope for the 6-hour build. Every minute not spent on the core demo loop is wasted.

  • Advertiser Dashboard web app — use direct cast commands to seed the AdPool for demo
  • Ad targeting system — use round-robin from 3 hardcoded ASCII creatives
  • Multi-model routing — just use claude-haiku-4-5 for everything
  • Production-grade wallet encryption — machine-ID key is fine for hackathon MVP
  • Redis / persistent session store — in-memory Map is sufficient for demo duration
  • Robust error recovery / retry logic — happy path only for the demo loop
  • Frequency capping / advanced anti-fraud — basic timing + session token is enough
  • Real advertiser onboarding flow — you are the advertiser for the demo
